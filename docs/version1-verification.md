# バージョン1 確認記録

確認日：2026-11-05。Unity Editor 6000.6.8f1、Pipeline 0.10.0-exp.1、Blender 5.2.3 LTS。

## 確認済み

- Blenderの画面上で7モデルを作成し、編集用blendとFBXを保存。レンダリングして形状を確認。外部ファイルの欠落なし。
- UnityでFBXをインポートし、保存済みの1部屋のシーンを再生。最終コンパイルのエラー・警告は0件。実行中のコンソールエラー0件。
- 実際のGUIクリックで、標本を開く、左ドラッグで回転、顕微鏡モードに切り替え、倍率変更を確認。
- 実際の床クリックで、訪問者の位置が変化することを確認。
- Input Systemへ上矢印の押下・解放イベントを送り、前方への移動を確認。右ボタンとマウス差分イベントを送り、カメラの水平・垂直角度が変化することを確認。
- 展示一覧からアンモナイト展示へ直接移動するGUI操作を確認。
- 解説を開く、FAQを選ぶ、回答が切り替わる、会話を閉じるGUI操作を確認。
- 移動先5か所の位置、標本3点の観察状態、顕微鏡3種への切り替え、FAQ3項目の非空回答を実行中に検証。
- 自動見学が通常速度で6段階を通り、自由見学へ戻ることを確認。標本観察2回と顕微鏡観察1回が実行された。
- 自動見学の一時停止をGUIで操作。進行時間と訪問者位置が変化しないことを2回の読み取りで確認し、再開して終了まで到達。
- 最終段階から繰り返す設定で最初の段階へ戻ること、および終了操作で自由見学へ戻ることを検証。
- Unityの全アセットファイルにmetaが存在すること、生成キャッシュがGit対象外であることを確認。
- 新規のテキストファイルに個人フォルダーや制作PCの絶対パスが含まれないことを検索で確認。Blenderのプレビュー出力先は相対パス。
- `git diff --check` で空白エラーなし。既存outputsと共有アセットは変更していない。

## 修正した問題

- 狭いGameビューで操作ボタンが隠れる問題：UI全体を画面寸法に合わせて縮小。
- 案内文字の大きさ、看板とFBXモデルの向き。
- 顕微鏡の移動先に誤って付いた当たり判定による、自動見学の停止。
- 自動見学の中央通路をNPCがふさぐ見え方：開始時に通路外側へ配置。
- 看板文字が物体越しに見える問題：奥行きを判定する文字用シェーダー。

## 未検証・対象外

- Windows単体アプリは依頼によりビルドしていない。Web、VR、モバイルも未検証。
- 標本と顕微鏡像は科学的な監修を行った資料ではなく、ダミー模型と模式図。
- 先生による操作感・画面酔い・見た目の評価はこれから。
- NPCの関節アニメーション、音声、自由入力のAI回答、床クリックの障害物迂回は未実装。
