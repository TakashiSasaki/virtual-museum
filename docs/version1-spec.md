# バーチャル展示室 バージョン1

## 合意した範囲

- 大学附属ミュージアムの写真を参考にした1部屋。寸法は仮設定で変更可能。
- 白い標本棚、茶色い標本箱、斜めの展示、作業台、顕微鏡。
- ダミー標本を選択して手元で回転・拡大・リセット・返却。
- 顕微鏡モードで仮の拡大資料を拡大・移動して観察。科学的な顕微鏡像とは区別する。
- 十字キー／WASDで移動、右ドラッグで視点変更、床のクリックで移動。
- 展示一覧から目的地へのショートカット。
- アイモナイト君の簡易モデルが巡回。会話中は停止。
- 用意した展示解説と選択式FAQ。自由入力・生成AI・外部APIは対象外。
- デモ用自動見学（開始・停止・再開・次へ・終了・繰り返し）。

## 制作方針

Blenderでモデルを作り、編集可能な元データを保存する。FBXをUnityのAssets内へ書き出し、Unityで室内配置・操作・UI・巡回・自動見学を実装する。既存のoutputs以下の構想と共有アセットは維持する。

PC上のローカル試作を対象とする。標本・説明・拡大図は仮資料。キャラクターは参考画像に基づく簡易造形で、正式モデルではない。音声、Web公開、実物資料の監修は対象外。

先生の指定によりWindows版はビルドせず、Unity EditorのGameビューで確認する。

## 確認する体験

1. 起動して室内が表示され、移動できる。
2. 展示を選び、標本を回転・拡大し、返却できる。
3. 顕微鏡モードに切り替え、倍率と観察位置を変えられる。
4. 解説とFAQが表示され、会話を閉じて探索に戻れる。
5. ショートカットで各展示・観察台・入口へ移動できる。
6. 自動見学を一時停止・再開・終了し、自由操作に戻れる。
7. GUI操作中に室内移動が誤作動せず、NPCが観察位置をふさがない。
