# 片手で続けられるタッチ操作

## 調査と採用判断（2026-11-07）

| 公式資料 | 確認した工夫 | 本展示室への適用 |
|---|---|---|
| [Mario Kart Tour / Nintendo](https://www.nintendo.com/store/products/mario-kart-tour-mobile/) | 指一本で操舵・ドリフトなどを操作 | 片手パッドの左右を旋回へ割り当て、前後移動と組み合わせる |
| [Sky Beta公式ヘルプ](https://thatgamecompany.helpshift.com/hc/en/13-sky-beta/faq/375-how-do-i-get-my-character-to-move/) | 片手／両手方式、左右配置の反転、パッド内の倒し量で速度調整。片手方式でもカメラは2本指 | 方式と左右配置の選択、倒し量による速度調整を採用。Skyの方式をそのまま再現するものではない |
| [Monster Hunter Now公式ヘルプ](https://scopelyexplore.helpshift.com/hc/en/15-monster-hunter-now/faq/2333-tips-gyro/) | 端末の傾きによる照準、強弱選択、対象へ向き直るリセット | 対象への向き直りは既存機能を活用。今回の実装はタッチのみとし、ジャイロは見送る |

上記からの設計上の判断として、停止して細部を見る展示室では、自動前進よりも「指を離せば必ず止まる」前後移動＋旋回が適すると考えた。中央長押しで歩行／見回しを切り替える操作は、この展示室用の独自の組み合わせであり、上記ゲームに同じ操作があるという主張ではない。

## 操作

初期設定は片手モード。既存の画面ドラッグ、床タップ、ショートカット、観察・ピンチ操作も利用できる。

- パッド上／下：前進／後退。倒し量で速度を調整。
- パッド左／右：その場で旋回。斜め：前後移動しながら曲がる。
- 中央を0.6秒長押し：停止したまま「見回し」に切替。上下左右で景色が指の方向へ流れる。
- 見回し後に中央へ戻して0.6秒待つ：歩行へ戻る。同じ指を置いたまま繰り返せる。
- 指を離す：停止して歩行モードへ戻る。中央に置き続けても切替は連発しない。
- パッドの外周が操作方向に発光。「前後・旋回」「切替…」「見回し」で状態を表示。
- 「メニュー」の操作方式ボタンで従来の両手モードへ切替。左右は平行移動に戻る。
- 「メニュー」でパッドを左右に配置可能。方式・配置は端末内に保存。
- 片手モードでも、別の指で展示室を触っている間はパッドを通常の移動にし、見回しを別の指へ任せる。

画面上の景色のドラッグは指の移動量に対応し、パッドは倒している間の速度に対応する。歩行パッドの右は「右へ曲がる」、見回しパッドの右は「景色を右へ動かす」という違いを、モード表示と案内で明示する。

中央のデッドゾーン、長押しの再準備条件、旋回速度上限を設ける。モード変更、メニュー、画面サイズ変更、フォーカス喪失では保持中の指を無効にし、意図しない移動の再開を防ぐ。

## 検証範囲

Unity Editorの390×844タッチ相当入力で前後＋旋回、中央長押し、停止見回し、中央復帰、指離し、両手入力、設定切替を確認した。13項目の入力経路チェックと、実際のメニューボタンへのタッチで、方式変更・左右配置・閉じる操作が通ることを確認済み。Webビルドはユーザーの指示待ち。スマートフォン実機での操作感・疲労感、Safari/Web版の検証は別途必要。
