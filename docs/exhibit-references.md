# 展示物の制作参考資料

展示室の23点とバックヤードの25点について、制作記録に残る資料と模型への使い方をまとめています。表中の英字IDはUnity用FBXのファイル名です。Blenderの元データ、生成スクリプト、確認画像の対応は各コレクションの説明に掲載しています。[展示室のコレクション](expanded-collection.md) · [バックヤードのコレクション](reserve-collection.md)

公開資料の写真・図版・本文は、形や特徴を調べるために参照しました。模型のメッシュと表面の模様は独自に制作しています。各模型は分類群の代表的な形や観察箇所を示す教材で、微生物の拡大・切開や化石の断面などを含みます。模型同士の寸法比は観察用に調整しています。
