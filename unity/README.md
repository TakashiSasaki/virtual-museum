# Unity バージョン1

## 起動

Unity HubまたはUnity CLIで `unity/VirtualMuseum/` を開きます。制作・確認に使用したEditorは **6000.6.8f1** です。

1. Project欄で `Assets/Museum/Scenes/MuseumV1.unity` を開く。
2. 上部の再生ボタン（▶）を押す。
3. Gameビュー内をクリックして操作する。

Gameタブのダブルクリックでビューを拡大できます。通常のレイアウトに戻すときもダブルクリックします。表示が狭い場合は16:9または16:10を選ぶと見やすくなります。Unity上の確認を対象とし、実行ファイルは作成していません。

## 操作

| 操作 | 方法 |
|---|---|
| 歩く | 十字キー／WASD |
| 見回す | 右ボタンを押しながらドラッグ |
| マウスで移動 | 通路の床を左クリック |
| 目的地へ直接移動 | 左下「展示一覧・移動」から展示・観察台・入口を選ぶ |
| 標本を手に取る | 標本をクリック、または右パネルの「標本を手に取る」 |
| 回転 | 観察画面内で左ドラッグ |
| 拡大・縮小 | ホイール、または＋／− |
| 観察をリセット | 「向き・倍率をリセット」 |
| 顕微鏡 | 「顕微鏡で見る」、または作業台の顕微鏡をクリック |
| 拡大図の観察位置 | 顕微鏡画面内で左ドラッグ（拡大時） |
| 標本を戻す | 「標本を戻して展示室へ」またはEsc |
| 解説・質問 | 「アイモナイト君の解説」またはNPCをクリック。質問は3つの選択肢 |
| 自動見学 | 左下「自動見学をはじめる」 |
| 自動見学の制御 | 一時停止／再開、次へ、繰り返しON/OFF、自由見学に戻る |

自動見学は6段階。通路を移動しながら、入口、標本展示、標本回転、顕微鏡、解説を紹介します。完了後は自由見学に戻ります。Escでも自動見学を終了できます。

## 試作の範囲と制限

- 1部屋、仮寸法12 × 14 m。展示点数は3点。
- コガネムシ、チョウ、アンモナイトは操作確認用のダミーモデル。実在する種や実物の形態を保証しません。
- 顕微鏡は生成した模式図。倍率はUI確認用で、実際の顕微鏡の倍率・解像度ではありません。
- アイモナイト君は参考画像から作った簡易造形。殻のシンボルは仮の装飾です。巡回と向きの変化を実装し、歩行の関節アニメーションや音声は未実装です。
- 解説は文字表示、質問は固定FAQ。生成AI、自由入力、音声認識、外部通信を使用しません。
- 床クリックは直線移動です。棚などを自動的に迂回する経路探索は未実装。障害物で止まった場合は別の通路位置をクリックするか、移動ショートカットを使います。
- PCのマウス・キーボード向け。タッチ操作、Web公開、VR、単体アプリの動作は未検証です。

## 制作ファイル

- `Assets/Museum/Models/`：Blenderから書き出したFBX 7点。
- `Assets/Museum/Textures/`：壁塗装、木目、白い化粧板、塗装金属、カーペット、床材、作業マットの繰り返し可能なテクスチャ。RGBは表面色、アルファは細かな凹凸用の高さ情報です。
- `Assets/Museum/Materials/Surfaces/` と `TriplanarSurface.shader`：壁、床、標本箱、机、棚に使う材質。寸法や向きの異なる面にも、空間内の位置に基づいてテクスチャを適用します。
- `Assets/Museum/Scripts/`：移動、観察、顕微鏡、FAQ、NPC、自動見学、UI。
- `Assets/Museum/Scenes/MuseumV1.unity`：編集可能な展示室。
- `Assets/Museum/Editor/MuseumBuilder.cs`：初回のシーン作成用。既存シーンの上書きを拒否します。通常は保存済みシーンを開いて編集してください。
- `../../blender/scenes/museum_v1_assets.blend`：Blender編集用元データ。`Museum V1 | Asset workshop` シーン。
- `../../work/build_v1_assets.py`：モデル作成の再現用。既存のV1元データの上書きを拒否します。

Blender元データとUnity用FBXは両方保持します。Blenderを編集した場合は対象モデルだけFBXを書き出してUnityに再インポートします。`Assets`内の`.meta`は維持してください。

Blender元データは、上記のテクスチャを `Assets/Museum/Textures/` から相対パスで参照します。別PCへのコピー時も、リポジトリ内のBlender元データとUnityプロジェクトの相対配置を保ってください。画像を別途コピーしたりBlenderに埋め込んだりする必要はありません。

テクスチャは `work/generate_material_textures.py` で再生成できます（NumPyが必要）。既存のPNGを置き換える場合は明示的に `--overwrite` を指定します。Unityの材質はモデルに埋め込まず、保存済みシーンの各部品に割り当てています。FBXの再インポートで割り当てが外れた場合は、シーンを保存して再生を止め、Unityの **Museum → Apply V1 Surface Materials** を実行してください。この操作はV1の対象部品に標準の材質を再適用します。Blender側の材質を再適用するためのスクリプトは `work/apply_v1_blender_materials.py` です。

## エージェント接続

Unity Pipeline `0.10.0-exp.1` を導入済みです。Editorを開いた状態で `unity status` から接続を確認できます。再生中の先生の操作とエージェントによる変更が競合しないよう、操作確認時はエージェントの変更を止めます。
