# Unity バージョン1

## 起動

Unity HubまたはUnity CLIで `unity/VirtualMuseum/` を開きます。制作・確認に使用したEditorは **6000.6.8f1** です。

1. Project欄で `Assets/Museum/Scenes/MuseumV1.unity` を開く。
2. 上部の再生ボタン（▶）を押す。
3. Gameビュー内をクリックして操作する。

Gameタブのダブルクリックでビューを拡大できます。通常のレイアウトに戻すときもダブルクリックします。狭い画面では操作パネルを下部へまとめる表示になります。Windowsの実行ファイルは作成していません。

[Web版](https://TakashiSasaki.github.io/virtual-museum/)では「展示室に入る」を押すと同じページ内で起動します。キーボード・マウスとタッチ操作に対応し、初回はプレイヤーデータを読み込みます。データ量はビルド内容によって変わります。スマートフォン実機での動作・性能は未検証です。[WebGLのビルド・更新・GitHub Pagesへの公開手順](../docs/web-publication.md)。

## 展示コレクション

回転・拡大して観察する対象は23点です。初期のコガネムシ・チョウ・アンモナイトを新しい教材模型に更新し、陸上・水生の昆虫、幼虫、クモ、微生物、鉱物、剥製型模型、内部の見える飼育箱を追加しました。「展示一覧・移動」（小画面では「移動」）から各展示へ移動でき、展示物や金色のサインから観察できます。[全23点と制作・検証範囲](../docs/expanded-collection.md)。

ミツバチとクモは、脚の数や体の区分を比べる別の展示です。ゴキブリとシロアリは、同じゴキブリ目の比較展示として室内中央奥の独立展示台に並べます。顕微鏡へ切り替えた際の画像は各題材に対応する生成模式図で、実際の標本を撮影した顕微鏡写真ではありません。

## 操作

| 操作 | 方法 |
|---|---|
| 歩く | 十字キー／WASD |
| 見回す | 右ボタンを押しながらドラッグ |
| マウスで移動 | 通路の床を左クリック |
| 目的地へ直接移動 | 左下「展示一覧・移動」から展示・観察台・入口を選ぶ |
| 標本を手に取る | 標本または金色のサインをクリック、近づいて標本を見ながらE、または右パネルの「標本を手に取る」 |
| 回転 | 観察画面内で左ドラッグ |
| 拡大・縮小 | ホイール、または＋／− |
| 観察をリセット | 「向き・倍率をリセット」 |
| 顕微鏡 | 「顕微鏡で見る」、作業台の顕微鏡または青緑のサインをクリック、または近づいて顕微鏡を見ながらE |
| 拡大図の観察位置 | 顕微鏡画面内で左ドラッグ（拡大時） |
| 標本を戻す | 「標本を戻して展示室へ」またはEsc |
| 解説・質問 | 「アイモナイト君の解説」、NPC、または追従する紫色のサインをクリック。質問は3つの選択肢 |
| 自動見学 | 左下「自動見学をはじめる」 |
| 自動見学の制御 | 一時停止／再開、次へ、繰り返しON/OFF、自由見学に戻る |

自動見学は6段階。通路を移動しながら、入口、標本展示、標本回転、顕微鏡、解説を紹介します。完了後は自由見学に戻ります。Escでも自動見学を終了できます。

### スマートフォン・タッチ画面

縦向きの画面では、上部の状態表示と下部の操作ボタンの間に展示室を表示します。説明や展示一覧はスクロールできるパネルで開き、閉じると見学へ戻れます。キーボードは必要ありません。

| 操作 | タッチでの方法 |
|---|---|
| 歩く・曲がる | 片手モード：パッドの上下で前後、左右で旋回、斜めで移動＋旋回。通路の床タップも可能 |
| 見回す | パッド中央を0.6秒長押しで停止見回しへ。中央に戻して待つと歩行へ復帰。展示室の1本指ドラッグ・両手操作も可能 |
| 目的地へ移動 | 「移動」で展示・観察台・入口を選択 |
| 観察・解説 | 展示物や光るサインをタップ。「メニュー」から解説も選択可能 |
| 標本の回転 | 観察中に1本指でドラッグ |
| 拡大・縮小 | 2本指のピンチ、または＋／− |
| 顕微鏡の観察位置 | 拡大した画像を1本指でドラッグ |
| 観察を終える | 画面左上の「戻る」 |
| 自動見学 | 「メニュー」→「自動見学をはじめる」。画面内で一時停止・次へ・終了 |

移動パッドは背景が透ける円形の台座と、陰影のある丸いつまみで表示します。スライドした方向の外周が青緑色に光り、斜め方向にも追従します。指を離すとつまみが中央へ戻り、方向表示も消灯します。

入口・読み込み・エラー・操作案内も小さい画面に合わせて配置します。画面の回転やブラウザーの表示領域の変化に追従し、ノッチやホームインジケーター部分を避けます。ページ全体の拡大操作は制限せず、3D画面内だけを展示室のタッチ操作に使います。

標本・顕微鏡の観察開始では、視点を対象へ少し寄せながら約0.9秒で観察表示へ移ります。標本から顕微鏡像への切り替えは約0.5秒、展示室へ戻る動きは約0.65秒です。訪問者の歩行位置は保ちます。UnityでEキー、Escでの復帰、自動見学との組み合わせを確認済みです。

## 操作できる場所の光るサイン

床に浮かぶ分割リングと、アイコン・日本語の操作案内で、観察や解説を開ける場所を示しています。

- 金色：観察対象23点。「クリックで手に取る」（タッチ時はタップ操作）。
- 青緑：顕微鏡3か所。「クリックでのぞく」。
- 紫色：アイモナイト君に追従する1か所。「クリックで解説」。

サイン自体をクリックすると、対応する標本・顕微鏡の観察、または案内役の解説を開きます。床のリングを踏むだけでは起動しません。標本・顕微鏡では、近づいて対象を見ると明るさが変わり、案内が「E で手に取る」「E でのぞく」へ切り替わります。この表示は、距離・視線・遮蔽物を確認する既存のEキー操作判定と共通です。アイモナイト君のサインはクリックで操作します。

体験後は、サインを残したままアイコンにチェックマークが付き、案内が「体験済み・もう一度」へ変わります。床の分割リングはチェック付きのつながった輪になり、明滅が落ち着きます。標本・顕微鏡・案内役それぞれの色は維持します。再び操作可能な距離で対象を見ると「体験済み・Eで観察」と表示され、クリックやEキーで何度でも観察できます。案内役は引き続きクリックで解説を開けます。[体験済みの表示](../outputs/v1/12_experienced_wayfinding.png)。

標本と顕微鏡は観察への切り替えが完了した時点、案内役は解説を開いた時点で体験を記録します。近づいたり移動ショートカットで到着しただけでは記録せず、観察への切り替え途中で戻った場合も新しく体験済みにはしません。顕微鏡は実際に使った台ごとの記録です。顕微鏡像を開くために内部で用意された標本は、標本の観察画面へ切り替わるまでその展示を体験済みにはしません。

履歴はその回のPlayモード中に保持し、移動ショートカット、自動見学の開始・終了、サインの無効化・再有効化では消えません。自動見学で実際に開いた観察・解説も記録します。新しいPlayセッションでは未体験から始まり、PlayerPrefsなどによる次回起動への保存は行いません。

観察中と出入りの視点移動中、会話・展示一覧・操作ガイドを開いている間、自動見学中はサインを隠します。カメラが近いときはサインの見かけの大きさを抑え、ごく近距離ではアイコンと文字を隠して標本を見やすくします。[室内のサイン](../outputs/v1/10_interaction_wayfinding.png)・[操作可能になったときの表示](../outputs/v1/11_wayfinding_ready.png)。

配置はHierarchyの **Interaction wayfinding** と、拡張展示用の **Expanded collection displays** 配下にある各アンカーを移動して調整できます。`MuseumWayfinding` コンポーネントの `landmarks` で、対象、表示名、`badgeHeight`（表示の高さ）を設定します。アイモナイト君用のアンカーは再生中に案内役の位置へ追従します。**Museum → Add Interaction Wayfinding** は初回配置用で、配置済みのシーンには重複追加しません。

表示とクリック判定は `Assets/Museum/Scripts/MuseumWayfinding.cs`、リングとアイコンの形状は `MuseumBeaconGeometry.cs` で生成し、`Assets/Museum/Wayfinding.shader` と共有マテリアル `Materials/Wayfinding/Interaction light.mat` で描画します。文字には既存の `Museum/WorldText` シェーダーを使います。サインは再生時に生成され、追加のLightやColliderを使いません。

## 試作の範囲と制限

- 1部屋、仮寸法12 × 14 m。観察対象は23点。
- 模型は公開された形態資料を参考に制作したもので、実物標本のスキャンや特定種の厳密な複製ではありません。観察しやすい寸法へ調整しており、展示物同士は実寸比ではありません。微生物の切開や細部の強調も教材としての表現です。
- 顕微鏡の外観は参考写真に合わせた双眼実体顕微鏡の試作モデルです。のぞいた際の画像は生成した模式図で、倍率はUI確認用です。実際の機種の倍率・解像度ではありません。
- アイモナイト君は複数方向の参考画像に基づく試作造形です。殻には約2巻きの深い渦巻き溝と背面の横方向の隆起を設け、外側の管が太くなって頭に沿う大きな出口へつながる形にしています。正面の図柄、手足、小物とともに、細部は引き続き調整できます。
- 手足の骨と、足元の移動・旋回に合わせて腕・膝・足首を動かす歩行制御を追加しました。接地中の足を床の位置に保ち、振り出す足を持ち上げます。UnityのPlayモードで巡回・接地・会話時の停止を確認済みです。現在の展示室の平らな床向けで、階段や斜面への対応、音声は未実装です。
- 解説は文字表示、質問は固定FAQ。生成AI、自由入力、音声認識、外部通信を使用しません。
- 床クリックは直線移動です。棚などを自動的に迂回する経路探索は未実装。障害物で止まった場合は別の通路位置をクリックするか、移動ショートカットを使います。
- マウス・キーボードとタッチ操作を実装しています。WebGL版はChromiumベースのブラウザーで確認しています。スマートフォン実機、Safari、Firefox、VR、Windows単体アプリの動作は未検証です。特に実機のメモリ使用量・発熱・描画速度は追加確認が必要です。

- `Assets/Museum/ExpandedCollection.asset`：展示名、解説、観察模型、顕微鏡模式図の対応を保持する `MuseumCollection` データ。`MuseumExperience.Collection.cs` が一覧・選択・模式図の切り替えを担当します。

- `../../blender/scenes/collections/`：編集用元データ4ファイル。対応する `work/` の生成スクリプト、材質、参照資料は[拡張コレクションの説明](../docs/expanded-collection.md)を参照してください。

- `Assets/Museum/Materials/Surfaces/` と `TriplanarSurface.shader`：壁、床、標本箱、机、棚に使う材質。寸法や向きの異なる面にも、空間内の位置に基づいてテクスチャを適用します。
- `Assets/Museum/Scripts/`：移動、観察、顕微鏡、FAQ、NPC、自動見学、UI。`AimoniteGait.cs` が骨を動かす歩行制御、`MuseumExperience.Immersion.cs` がEキー操作と観察時の視点・表示の遷移を担当します。
- `Assets/Museum/Scenes/MuseumV1.unity`：編集可能な展示室。
- `Assets/Museum/Editor/MuseumBuilder.cs`：初回のシーン作成用。既存シーンの上書きを拒否します。通常は保存済みシーンを開いて編集してください。
- `../../blender/scenes/museum_v1_assets.blend`：Blender編集用元データ。`Museum V1 | Asset workshop` シーン。
- `../../work/build_v1_assets.py`：モデル作成の再現用。既存のV1元データの上書きを拒否します。
- `../../work/build_lab_seating.py`：研究室用の背付き回転椅子と丸い回転スツールを追加・再生成します。`work/render_lab_seating.py` で確認画像を生成できます。
- `../../work/build_lab_storage.py`：台下引出、2段ワゴン、両開き収納棚を追加・再生成します。`work/render_lab_storage.py` で確認画像を生成できます。どちらの生成処理も、自分で作成したタグ付き什器だけを更新し、元データの他のモデルを保持します。
- `Assets/Museum/Editor/MuseumLabFurniture.cs`：保存済みのシーンへ追加什器12点を配置します。**Museum → Add Laboratory Furniture** は初回追加用で、配置済みの場合は重複追加を拒否します。通常の位置調整はHierarchyの `Lab furnishings` 配下で行います。

- `../../work/refine_aimonite.py`：開いているV1元データのアイモナイト君だけを作り直し、対応するFBXを更新します。保存済みの元データで実行してください。
- `../../work/aimonite_turnaround.py`：現在のアイモナイト君を再生成する入口です。殻の巻き数・溝の深さ・隆起はスクリプト内で調整できます。以下の補助スクリプトも読み込み、元データ内のアイモナイト君とUnityのFBXを更新します。実行前に対象と保存状態を確認してください。
- `../../work/aimonite_symbols.py`：殻の正面に沿う色付きの図形と輪郭線。
- `../../work/aimonite_aperture.py`：外側の管を出口へ向けて太くし、丸い縁と頭に沿った開口を殻へ一体化します。開口の位置・大きさを調整できます。
- `../../work/rig_aimonite.py`：手足の編集可能な骨と、骨に追従するメッシュの設定。Unityの歩行制御が名前付きの骨を動かします。
- `../../work/render_aimonite.py`：正面・斜め前・側面・背面・斜め後ろの確認画像を `../../blender/previews/` に出力します。保存済みの元データを別のBlenderプロセスで開いて使います。レンダリング用の表示設定は変更しますが、blend自体は保存しません。

造形の確認画像：[正面](../blender/previews/aimonite_front.png)・[斜め前](../blender/previews/aimonite_angle.png)・[側面](../blender/previews/aimonite_side.png)・[背面](../blender/previews/aimonite_back.png)・[斜め後ろ](../blender/previews/aimonite_back_angle.png)。確認内容と未確認事項は[確認記録](../docs/version1-verification.md)を参照してください。

Blender元データとUnity用FBXは両方保持します。Blenderを編集した場合は対象モデルだけFBXを書き出してUnityに再インポートします。`Assets`内の`.meta`は維持してください。

Blender元データは、上記のテクスチャを `Assets/Museum/Textures/` から相対パスで参照します。別PCへのコピー時も、リポジトリ内のBlender元データとUnityプロジェクトの相対配置を保ってください。画像を別途コピーしたりBlenderに埋め込んだりする必要はありません。

手続き生成のテクスチャは `work/generate_material_textures.py` で再生成できます（NumPyが必要）。写真素材はこの処理では上書きしません。既存のPNGを置き換える場合は明示的に `--overwrite` を指定し、`--only VinylFloor` のように対象を絞れます。Unityの表面材質は保存済みシーンの各部品に割り当てています。FBXの再インポートで割り当てが外れた場合は、シーンを保存して再生を止め、Unityの **Museum → Apply V1 Surface Materials** を実行してください。顕微鏡には **Museum → Apply Microscope Materials** を実行します。Blender側の表面材質を再適用するスクリプトは `work/apply_v1_blender_materials.py` です。

照明は白に近い天井灯と上下で明るさの異なる環境光に調整し、中央の天井灯4個に柔らかい影を設定しています。室内の反射用プローブは256pxで起動時に1回更新します。現在のPCで動作確認していますが、低性能端末での性能検証はしていません。

## 追加した研究室什器

背付き回転椅子3脚、丸い回転スツール2脚、作業台下の引出3台、2段ワゴン2台、奥壁の両開き収納棚2台を配置しています。椅子は五本脚・双輪キャスター・昇降軸・高さ調節レバーがあり、丸椅子には足置きリングも付いています。座面高は約54cm。家具は静止した配置物で、着座や座面を回す操作はまだありません。

顕微鏡の正面を空けるため、椅子を横へ65cmずらしています。各家具には個別の当たり判定があり、追加家具が移動ショートカット先や中央通路を塞がない配置です。作業床上の家具は床の上面の高さ2.2cmへ合わせています。

Blenderでは部品を個別に編集でき、Unity用FBXでは同じ材質の部品をまとめます。12点の追加で描画メッシュは65個、共有材質は8種類です。[室内の配置](../outputs/v1/06_lab_furniture.png)・[椅子の形状](../blender/previews/lab_seating.png)・[収納の形状](../blender/previews/lab_storage.png)。

## エージェント接続

Unity Pipeline `0.10.0-exp.1` を導入済みです。Editorを開いた状態で `unity status` から接続を確認できます。再生中の先生の操作とエージェントによる変更が競合しないよう、操作確認時はエージェントの変更を止めます。

## 追加展示用の素材バンク

昆虫14点、化石5点、土器・石器6点を Assets/Museum/ReserveCollection.asset に登録しています。Museum → Prepare Reserve Collection で再構成できます。現行展示とは別管理です。[一覧・利用方法](../docs/reserve-collection.md)。

インジケーターを選ぶと約0.8秒で実際の対象へ向き直り、その後に観察・解説へ移ります。展示一覧からの移動も到着後に視線を合わせます。手動移動・見回しで向き直りを中断できます。タッチの見回しは指で景色をつかむ方向（右スワイプで景色が右、上スワイプで景色が上）です。

片手／両手の方式とパッドの左右配置は「メニュー」で変更・保存できます。初期設定は片手・左配置です。[調査したゲームの公式資料、設計判断、操作の詳細と検証範囲](../docs/one-handed-controls.md)。
