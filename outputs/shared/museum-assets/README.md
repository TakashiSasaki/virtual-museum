# 共有アセットの使い方

展示室の `museum_walkthrough_linked.blend` は、次のファイルを相対パスで参照します。フォルダーごとコピーし、両ファイルを `shared/museum-assets/` に置いたままにしてください。

- `furniture.blend`：展示ケース3種類、閲覧台2種類、白い展示台、見学ベンチ。
- `exhibits.blend`：球体・環・立体の彫刻、アザラシ模型。

各アセットはコレクションとして保存され、原点は床面にあります。同じ展示台やケースの複数配置は、それぞれ同じコレクションを参照します。壁、照明、写真、陶器や昆虫など、展示室に残した要素もあります。写真は展示室の `.blend` 内に埋め込まれています。

## 共有アセットを編集する

1. 編集したい共有 `.blend` を開きます。展示室に未保存の変更がある場合は、先に保存するか別の Blender ウィンドウを使ってください。
2. 画面右上のシーン選択から `編集 | 展示ケース_標準` などを選びます。各シーンには対応するアセットが原点付近に表示されます。
3. 部品や材質を編集して、共有 `.blend` を保存します。各アセットの原点とコレクション名をむやみに変えると、参照先の配置やリンクに影響するため注意してください。
4. 展示室を開き直すか、アウトライナーの表示を **Blender File** に変えて対象ライブラリを右クリックし **Reload** します。共有アセットの更新は、それをリンクする展示室に反映されます。

## 展示室で配置を変える・別の作品で使う

展示室のアウトライナーで `リンクされた共有アセット` を展開し、`展示ケース_標準 | 配置 01` のようなインスタンスを選択します。位置・回転・大きさは展示室側で調整できます。アセット自体の形状を変更したい場合は上記の共有ファイルを編集します。

別の作品では **File → Link** で `furniture.blend` または `exhibits.blend` を選び、`Collection` の中から対象を選択します。**Relative Path** と **Instance Collections** を有効にすると、アセットを共有したまま位置などを変更できます。参照元と共有ファイルを一緒に移す場合は相対的な位置関係を保ってください。Asset Browser を使う場合は、この `museum-assets` フォルダーを Blender のアセットライブラリに登録し、取り込み方式を **Link** に設定できます。

## Git での扱い

現時点では展示室とこのフォルダーは同じ Git リポジトリにあります。共有アセットを別リポジトリに分けて submodule 化する場合は、参照パスを維持したまま別途設定してください。Git LFS は使用していません。
